# User Guide: Student Task Manager

Welcome to the Student Task Manager! This simple tool helps you keep track of your daily tasks directly from your command line.

## Getting Started
When you start the application, you will see a numbered list of your tasks. 
* `[ ]` means the task is pending.
* `[x]` means the task is completed.

## Operations
* **Adding a Task:** Choose the "Add" option and type your task description. Note: You cannot submit a blank task!
* **Completing a Task:** Choose the "Complete" option and enter the number next to the task you want to check off.
* **Deleting a Task:** Choose the "Delete" option and enter the task number. Be careful, as this permanently removes it from your list.
